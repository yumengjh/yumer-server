# AI Chat V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a backend AI chat module that stores isolated user conversations, messages, and model context snapshots while calling an OpenAI-compatible endpoint through LangChain.js.

**Architecture:** Add an isolated NestJS `AiModule` with controller, conversation service, model adapter, and prompt builder. Persist business chat history in TypeORM entities, and keep LangChain isolated inside `AiModelService` so future LangGraph workflows can reuse the same conversation IDs.

**Tech Stack:** NestJS 11, TypeORM, Jest, class-validator, LangChain.js `@langchain/openai`.

---
