# 留言板模块迁移与增强方案

## Context

将 `back/server-old` 的留言功能迁移到 `back/server`，增加敏感词过滤、点赞/表情回应、留言置顶。
表情回应设计为通用模块，后续可复用于文档、页面等场景。本次仅实现后端。

## 模块架构

```
src/modules/
├── reactions/                       # 通用表情回应模块（独立，可复用）
│   ├── reactions.module.ts
│   ├── reactions.controller.ts      # GET /reactions/emojis, POST/DELETE reactions
│   ├── reactions-admin.controller.ts # 管理表情目录 + 查看回应记录
│   ├── reactions.service.ts
│   ├── dto/

│       ├── emoji.entity.ts          # 表情目录
│       └── reaction.entity.ts       # 回应记录（多态关联）

│   ├── guestbook.service.ts         # 留言 CRUD + 置顶

```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | integer PK | |
| targetType | varchar(50) | 目标类型: "guestbook", "document", "page" |
| targetId | varchar(100) | 目标 ID（兼容 string/number） |
| emojiId | integer FK → emojis.id | |

## API 设计

### Reactions 模块 — 公开

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/reactions/emojis` | 获取可用表情列表 |
| GET | `/api/v1/reactions/:targetType/:targetId` | 获取目标的所有回应统计 |
| POST | `/api/v1/reactions/:targetType/:targetId` | 添加回应 `{ emojiId }` |
| DELETE | `/api/v1/reactions/:targetType/:targetId/:emojiCode` | 取消回应 |

### Reactions 模块 — 管理（Admin JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/reactions/emojis` | 表情列表（含禁用） |
| POST | `/api/v1/admin/reactions/emojis` | 添加表情 |
| PATCH | `/api/v1/admin/reactions/emojis/:id` | 编辑表情 |
| DELETE | `/api/v1/admin/reactions/emojis/:id` | 删除表情 |
| GET | `/api/v1/admin/reactions/records` | 回应记录列表（支持 targetType 筛选） |
| DELETE | `/api/v1/admin/reactions/records/:id` | 删除回应记录 |

### Guestbook 模块 — 公开

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/guestbook` | 获取已审核留言（分页，置顶优先） |
| POST | `/api/v1/guestbook` | 提交留言（敏感词检测） |
| POST | `/api/v1/guestbook/:id/like` | 点赞/取消 |
| GET | `/api/v1/guestbook/:id/replies` | 获取回复列表 |

### Guestbook 模块 — 管理（Admin JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/admin/guestbook` | 全部留言（支持 status 筛选，含 ip） |
| PATCH | `/api/v1/admin/guestbook/:id` | 更新状态/置顶 |
| DELETE | `/api/v1/admin/guestbook/:id` | 删除留言 |
| POST | `/api/v1/admin/guestbook/batch-status` | 批量更新状态 |
| GET | `/api/v1/admin/sensitive-words` | 敏感词列表 |
| POST | `/api/v1/admin/sensitive-words` | 添加敏感词 |
| PATCH | `/api/v1/admin/sensitive-words/:id` | 编辑 |
| DELETE | `/api/v1/admin/sensitive-words/:id` | 删除 |

## 敏感词过滤逻辑

1. 启动时预加载所有 `isActive=true` 的敏感词到内存 Set
2. 提交留言时扫描 content
3. 命中 → `status=0`（待审核），替换敏感词为 `replacement`
4. 未命中 → `status=1`（自动通过）
5. 管理员增删改敏感词后刷新内存缓存

## 实施顺序

1. **reactions 模块** — entity → service → controller → admin controller → module → 注册
2. **guestbook entity** — guestbook + guestbook-like + sensitive-word
3. **sensitive-word service** — 内存缓存 + 过滤逻辑
4. **guestbook service** — CRUD + 置顶
5. **guestbook-like service** — toggle 点赞
6. **guestbook controller** — 公开 API
7. **guestbook admin controller** — 管理 API
8. **guestbook module** — 注册到 app.module

## 验证方式

```bash
# 1. 获取表情列表
curl http://localhost:5200/api/v1/reactions/emojis

# 2. 提交留言（无敏感词 → 自动通过）
curl -X POST http://localhost:5200/api/v1/guestbook \
  -H 'Content-Type: application/json' \
  -d '{"nickname":"test","content":"hello world"}'

# 3. 提交含敏感词留言 → 待审核
curl -X POST http://localhost:5200/api/v1/guestbook \
  -H 'Content-Type: application/json' \
  -d '{"nickname":"test","content":"包含敏感词的内容"}'

# 4. 点赞
curl -X POST http://localhost:5200/api/v1/guestbook/1/like

# 5. 添加表情回应
curl -X POST http://localhost:5200/api/v1/reactions/guestbook/1 \
  -H 'Content-Type: application/json' \
  -d '{"emojiId":1}'
```
